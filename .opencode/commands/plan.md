Break down the current spec into independent, executable tasks.

Load and follow: skills/core/planning/SKILL.md

## Principles
- Each task should be completable by a single subagent in one worktree
- Tasks should be "bite-sized" — a few hours max
- Independent tasks can run in parallel
- Dependent tasks must have clear dependencies declared

## Output Format
For each task:
- Task ID (e.g., TASK-001)
- Task name
- Assigned agent
- Acceptance criteria
- Dependencies (other task IDs)
